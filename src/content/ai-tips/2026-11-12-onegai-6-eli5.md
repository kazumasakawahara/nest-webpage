意思決定支援という言葉は、研修でも会議でも何度も聞きます。ところが、ご本人に「意思決定支援って何？」と聞かれたら、どう答えるでしょう。ガイドラインは長く、言葉はかたい。説明しようとするほど、こちらの言葉が増えていきます。

今回は、その説明を **一行の頼み方で、絵の地図にしてもらった** 実例です。使ったのは、Claude Code の「ELI5（イーエルアイファイブ）」という道具。むずかしい話の細かいところに入る前に、まず全体の地図を一枚もらうための道具です。

## 1. ELI5 ― 頼み方を一枚のカードにした道具

ELI5 は「Explain Like I'm 5」の頭文字で、「5歳の子にも分かるように説明して」という意味の英語の言い回しです。私はこの道具を、kazu（谷 一徳）さんの note の記事「<a href="https://note.com/kazu_t/n/n34de0b43f0fa" target="_blank" rel="noopener">【2026年8月版】ELI5とは？Claude CodeからELI5を使ってみた。難しい話を図で理解しよう！</a>」で知りました。この回の土台は、kazuさんの記事です。

kazuさんの記事によると、ELI5 の中身は驚くほど短いそうです。書いてあるのは、ほぼ次の一文だけ。「その分野について何も知らない人に向けて、大きな絵と、とても少ない言葉で、HTML のページにして説明して」。外の道具につなぐ仕掛けも、特別なプログラムも入っていません。kazuさんは、ELI5 を「正確な仕様を調べる道具」ではなく、複雑なしくみの全体像を短い時間でつかむための「**理解の入口**」と紹介しています。

この特集を読んできた方には、見覚えのある頼み方のはずです。<a href="/ai-tips/2026-09-11-onegai-1-html/">その1</a>で、答えを「図（HTMLが良い）」で出してもらいました。ELI5 は、あの頼み方を<a href="/ai-tips/2026-07-17-ai-skills-recipe-card/">スキルという名のレシピカード</a>にして、一行で呼べるようにしたものです。カードにしておけば、長い頼み方を毎回打たなくて済みます。

入れ方は、kazuさんの記事に書いてある手順のとおりです（Claude Code の例です。2026年11月時点）。ターミナルという、文字を打ってパソコンに指示する画面で、次の二行を順に打ちます。

<div class="ai-prompt">
  <span class="ai-prompt__label">ELI5 を入れる二行（kazuさんの記事より）</span>
  claude plugin marketplace add anthropics/claude-plugins-community<br>
  claude plugin install eli5@claude-community
</div>

配っているのは Anthropic が管理するコミュニティ向けの棚で、Anthropic の公式の道具ではありません。作者は Anthropic の Thariq Shihipar さんで、MIT ライセンスで公開されています（Claude Code そのものの利用料は、ご自身の契約によります）。これも kazuさんの記事に書いてあることです。

## 2. 私が送った一行（原文のまま）

私は、意思決定支援を題材にしました。送ったのは、次の一行です。

<div class="ai-prompt">
  <span class="ai-prompt__label">実際に送った依頼文（原文のまま）</span>
  /eli5:eli5 知的障害者に対する意思決定支援について説明して。自分のことを決めるのは私の権利であること、そのことは相手に言えることも忘れずに入れて
</div>

先頭の「/eli5:eli5」が、カードを呼び出す合図です（kazuさんの記事では「/eli5」と書かれています）。そのあとは、ふつうの話し言葉です。「ひらがなで」「本人向けに」「絵を何枚」といった注文は、一つも書いていません。

自分で足した注文は、二つだけです。**決めるのは私の権利であること。そして、そのことを相手に言えること。** 意思決定支援を説明するなら、ここだけは外してほしくありませんでした。

## 3. 返ってきたもの ― ご本人が読める絵の地図

返ってきたのは、縦に長い一枚のページでした。題は「わたしの ことは わたしが きめる」。

<figure class="mockup mockup--shot mockup--wide">
  <img src="/images/ai-tips/onegai-6-eli5-top.webp" alt="返ってきたページの冒頭。大きな丸い文字で「わたしの ことは わたしが きめる」、その下に小さく「いしけってい しえん の はなし」。その下の絵では、オレンジの服の人が、左のりんごと右のコップを前に「これに する」と言い、コップに緑のチェックが付いている" width="1200" height="1200" loading="lazy" decoding="async" />
  <figcaption>▲ 返ってきたページの冒頭。文字はひらがなで、言葉ごとに間が空いています</figcaption>
</figure>

ページは、絵と短い言葉の組が6つ並ぶつくりです。

1. **きめるのは あなた** ― 食べるもの、着る服、住むところ、仕事、お金の使い方
2. **まわりの ひとは てつだう** ― 支援する人や家族は「あなたの かわりに きめる ひと では ありません」
3. **こんな ふうに てつだうよ** ― 絵や写真で分かりやすく、選べるように並べる、ゆっくり待つ、気持ちを聞く
4. **じぶんの ことを きめるのは わたしの 権利（けんり）** ― 障害があっても同じ。「あなたには むり」と言われても、なくならない
5. **あいてに いって いい** ― そのまま相手に見せられる言葉が5つ
6. **おぼえて おいてね** ― 決めたあとで変えてもいい、失敗しても大丈夫、「いまは決めない」も選べる、聞いてもらえないときは信じられる人に相談

いちばん下には、小さな字で「しえん する かたへ」という支援者向けの一段落も付いていました。

ページそのものを、ここに置いておきます。AI が出したまま、手を加えていません。押すと別のタブで開きます。

      <span class="app-card__desc">ELI5 が出したページを、そのまま置いています。5つ目の絵の下にある言葉を押すと、文字が画面いっぱいに大きくなります</span>
    </span>
    <span class="app-card__open">開いてみる</span>
  </a>
</div>

驚いたのは、**ひらがなで、ご本人に向けて書かれていたこと**です。私は「本人向けに」とは一言も書いていません。ELI5 は「何も知らない人に」という自分のカードと、「意思決定支援」という題材を合わせて、読み手はご本人だと受け取ったようです。ご本人向けの部分で使われた漢字は「権利」だけで、そこにはふりがなが振ってありました。

## 4. 「相手に言える」が、見せる道具になった

もう一つ驚いたのが、5つ目の絵でした。

<figure class="mockup mockup--shot mockup--wide">
  <img src="/images/ai-tips/onegai-6-eli5-say.webp" alt="5つ目の絵。オレンジの服の人が、青い服の人に向かって大きな吹き出しで「わたしが きめたいです」と言っている。その下に「あいてに いって いい」という見出しと、押せる言葉が5つ並ぶ。「わたしの ことは わたしが きめます」「わかる ように せつめい して ください」「かんがえる じかんを ください」「わたしの きもちを きいて ください」「きめるのは わたしの 権利 です」。一番下に「ことばを おすと、おおきく なります。あいてに みせて つかえます。」" width="1200" height="1835" loading="lazy" decoding="async" />
  <figcaption>▲ 「相手に言える」は、押せる言葉の札になって返ってきました</figcaption>

言葉を押すと、その一文だけが画面いっぱいに大きく出ます。

  <img src="/images/ai-tips/onegai-6-eli5-show.webp" alt="「わたしの ことは わたしが きめます」という一文だけが、画面いっぱいの大きな丸い文字で表示され、その下に「とじる」のボタンがある" width="1200" height="821" loading="lazy" decoding="async" />

私が頼んだのは「相手に言えることも入れて」までです。「押すと大きくなる札を」とは書いていません。AI は「言える」を「言うときに使える」まで進めて、口に出しにくい人でも見せれば伝わる形にしてきました。その1で、頼んでいないボタンが付いてきたのと同じ種類の驚きです。

## 5. どこが効いたのか ― カードは型、芯は自分で渡す

振り返ると、効いたものは二つありました。

一つ目は、ELI5 というカードです。**「何も知らない人に、大きな絵と少ない言葉で」という型**が、ひらがな、言葉の間の空白、絵が先で言葉が後という、ページ全体の形を決めました。これを毎回自分で書こうとしたら、かなり長い頼み方になります。

二つ目は、「忘れずに入れて」と自分で足した二つです。型だけなら、意思決定支援の一般的な説明で終わったはずです。実際には、「権利」の絵はページの中で一つだけ太い枠で囲まれ、「相手に言える」は札になりました。**カードが決めるのは形で、何を外してはいけないかは、頼む人が決めます。** 福祉の現場の人が使う意味は、ここにあると思います。何を芯にするかは、現場を知っている人にしか分からないからです。

ひとつ、気をつけたいこともあります。「5歳の子にも分かるように」という名前ですが、kazuさんの記事にあるとおり、本当の狙いは「専門の知識がない人にも分かる形に組み替える」ことです。大人のご本人に、ひらがなの絵のページが合うかどうかは、人によって違います。**渡す前に、その人に合う言葉と絵かどうかを、支援者が確かめます。** 漢字のほうが読みやすい人には「漢字にふりがなを付けて」と、一言足して作り直せます。

## 6. 地図は、道案内の代わりにならない

ELI5 がくれるのは、全体の地図です。細かい道順や、通れない道の情報までは載っていません。kazuさんの記事でも、向かない使い方として「正確な仕様や数値を確認したい」「法律、医療、金融などの重要な判断をしたい」が挙げられています。

今回のページの一番下の「しえん する かたへ」にも、根拠として障害者権利条約の第12条と、厚生労働省の意思決定支援ガイドライン（2017年）の名前が出てきます。これも AI の答えです。研修の資料や、ご家族への説明に使うなら、**条文の名前や年は、原典を開いて確かめてから**使ってください。絵が分かりやすいほど、中身まで正しく見えてしまうからです。<a href="/ai-tips/2026-07-28-ai-confidently-wrong/">AIは、自信満々にまちがえる</a>話は、あんしん編にあります。

もう一つ。題材に、特定の利用者さんの名前や様子を書き込まないでください。今回の一行も、意思決定支援という一般的な話だけで頼んでいます。どこまで話してよいかの線引きは、<a href="/ai-tips/2026-07-28-ai-privacy-line/">AIに話していいこと、いけないこと</a>の回に書いてあります。

## 7. Google（Gemini）や、Claude Code を使わない場合

ELI5 のカードは Claude Code 用です。けれど、中身はたった一文の頼み方なので、ほかの AI でも同じことができます。

Gemini なら、カードの代わりに Gem に覚えさせます。Gem の指示の欄に「何も知らない人に向けて、大きな絵と少ない言葉で、1枚のページにして説明する」と書いておけば、毎回は打たずに済みます。作り方は<a href="/ai-tips/2026-08-23-google-2-gem-studio/">Gemをつくる</a>の回にあります。ページの形で返してほしいときは、<a href="/ai-tips/2026-07-10-gemini-canvas/">Gemini Canvas</a>を使うと、その場で表示されます。

claude.ai や Claude のアプリでも、同じ一文を頭に付けて頼めば、絵のページが返ってきます。カードがなくても、頼み方そのものは誰でも使えます。

## 8. 今日ためすなら

まずは、カードを入れなくてもできる形で試してみてください。次の文の「〇〇」を入れ替えて、そのまま送ります。

<div class="ai-prompt">
  <span class="ai-prompt__label">ELI5 と同じ頼み方（日本語にしたもの）</span>
  〇〇について、この分野をまったく知らない人に向けて、大きな絵と少ない言葉で、1枚のページ（HTML）にして説明してください。必ず入れてほしいこと：〇〇
</div>

肝心なのは、最後の「必ず入れてほしいこと」です。ここに、現場の人として外してほしくない一点を書きます。

試しやすいテーマを、いくつか挙げておきます。どれも、細かい話に入る前に全体の地図がほしくなる話です。

- 障害福祉サービスを使い始めるまでの流れ（相談から、利用が始まるまで）
- 成年後見と任意後見の違い
- AI が自信満々にまちがえるのはなぜか（AI は、次に来そうな言葉を選んで文を作っています）
- AI の「手足」になる道具、MCP のしくみ

地図を一枚もらってから原典やガイドラインを読むと、いま自分が地図のどこを読んでいるのかが分かります。
