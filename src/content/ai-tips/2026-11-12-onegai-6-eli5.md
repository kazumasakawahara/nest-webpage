意思決定支援という言葉は、研修でも会議でも何度も聞きます。ところが、ご本人に「意思決定支援って何？」と聞かれたら、どう答えるでしょう。ガイドラインは長く、言葉はかたい。説明しようとするほど、こちらの言葉が増えていきます。

今回は、その説明を **一行の頼み方で、挿絵入りの1枚にしてもらった** 実例です。使ったのは、Claude Code の「ELI5（イーエルアイファイブ）」という道具。むずかしい話の細かいところに入る前に、まず全体像を絵でつかむための道具です。

## 1. ELI5 ― 頼み方を一枚のカードにした道具

ELI5 は「Explain Like I'm 5」の頭文字で、「5歳の子にも分かるように説明して」という意味の英語の言い回しです。私はこの道具を、kazu（谷 一徳）さんの note の記事「<a href="https://note.com/kazu_t/n/n34de0b43f0fa" target="_blank" rel="noopener">【2026年8月版】ELI5とは？Claude CodeからELI5を使ってみた。難しい話を図で理解しよう！</a>」で知りました。この回の土台は、kazuさんの記事です。

kazuさんの記事によると、ELI5 の中身は驚くほど短いそうです。書いてあるのは、ほぼ次の一文だけ。「その分野について何も知らない人に向けて、大きな絵と、とても少ない言葉で、HTML のページにして説明して」。外の道具につなぐ仕掛けも、特別なプログラムも入っていません。kazuさんは、ELI5 を「正確な仕様を調べる道具」ではなく、複雑なしくみの全体像を短い時間でつかむための「**理解の入口**」と紹介しています。

この特集を読んできた方には、見覚えのある頼み方のはずです。<a href="/ai-tips/2026-09-11-onegai-1-html/">その1</a>で、答えを「図（HTMLが良い）」で出してもらいました。ELI5 は、あの頼み方を<a href="/ai-tips/2026-07-17-ai-skills-recipe-card/">スキルという名のレシピカード</a>にして、一行で呼べるようにしたものです。カードにしておけば、長い頼み方を毎回打たなくて済みます。

入れ方は、kazuさんの記事に書いてある手順のとおりです（Claude Code の例です。2026年11月時点）。ターミナルという、文字を打ってパソコンに指示する画面で、次の二行を順に打ちます。

<div class="ai-prompt">
  <span class="ai-prompt__label">ELI5 を入れる二行（kazuさんの記事より）</span>
  claude plugin marketplace add anthropics/claude-plugins-community<br>
  claude plugin install eli5@claude-community
</div>

配っているのは Anthropic が管理するコミュニティ向けの棚で、Anthropic の公式の道具ではありません。作者は Anthropic の Thariq Shihipar さんで、MIT ライセンスで公開されています（Claude Code そのものの利用料は、ご自身の契約によります）。これも kazuさんの記事に書いてあることです。

## 2. 私が送った一行（原文のまま）

私は、意思決定支援を題材にしました。送ったのは、次の一行です。

<div class="ai-prompt">
  <span class="ai-prompt__label">実際に送った依頼文（原文のまま）</span>
  /eli5:eli5 知的障害者に対する意思決定支援について説明して。自分のことを決めるのは私の権利であること、そのことは相手に言えることも忘れずに入れて
</div>

先頭の「/eli5:eli5」が、カードを呼び出す合図です（kazuさんの記事では「/eli5」と書かれています）。そのあとは、ふつうの話し言葉です。「ひらがなで」「本人向けに」「絵を何枚」といった注文は、一つも書いていません。

自分で足した注文は、二つだけです。**決めるのは私の権利であること。そして、そのことを相手に言えること。** 意思決定支援を説明するなら、ここだけは外してほしくありませんでした。

## 3. 返ってきたもの ― ご本人が読める、挿絵入りの1枚

返ってきたのは、縦に長い一枚のページでした。題は「わたしの ことは わたしが きめる」。上から順に、絵と短い言葉の組が6枚並んでいます。

2枚目では、青い服の支援者が、絵のカードを見せて「どれが いい？」と聞いています。下の一文は「あなたの かわりに きめる ひと では ありません。」。研修なら「代行決定ではない」と説明するところを、ひらがな一行で言い切っています。

3枚目は、手伝い方の4つです。絵や写真で分かりやすくする。選べるように並べる。ゆっくり待つ。気持ちを聞く。支援者が日ごろ心がけていることが、小さな札4枚になっています。

  <figcaption>▲ 4枚目「じぶんの ことを きめるのは わたしの 権利」。この1枚だけ、太い枠で囲まれていました</figcaption>

4枚目が、私が「忘れずに」と頼んだ一つ目です。盾に守られた人の絵に、「しょうがいが あっても、おなじ です」「『あなたには むり』と いわれても、この 権利は なくなりません」と続きます。

どの絵の言葉も、ひらがなで、ご本人に語りかける形でした。私は「本人向けに」とは一言も書いていません。ELI5 は「何も知らない人に」という自分のカードと、「意思決定支援」という題材を合わせて、読み手はご本人だと受け取ったようです。ご本人向けの部分で使われた漢字は「権利」だけで、そこにはふりがなが振ってありました。

5枚目が、頼んだ二つ目の「相手に言える」です。

## 5. ELI5 はカレールー ― 箱の味に、うちの具を入れる

カレーを作るとき、多くの家ではルーの箱を使います。ルーを入れれば、誰が作ってもそれらしいカレーになります。けれど、じゃがいもを大きく切るか、豚肉か鶏肉か、隠し味に何を入れるかで、「うちのカレー」になります。

ELI5 は、このルーに当たります。「何も知らない人に、大きな絵と少ない言葉で」という味の土台が箱に入っていて、ひらがな、言葉の間の空白、絵が先で言葉が後というページの形は、ルーが決めてくれました。同じものを一から作ろうとしたら、長い頼み方が要ります。

具にあたるのが、「忘れずに入れて」と私が足した二つです。ルーだけなら、意思決定支援の一般的な説明で終わったはずです。実際には、「権利」の絵は一枚だけ太い枠で囲まれ、「相手に言える」は札になりました。何を外してはいけないかは、現場を知っている人にしか分かりません。**ルーは箱から出せても、具を選ぶのは頼む人です。**

ルーの味が、家族みんなの口に合うとは限りません。子ども向けの甘口が大人には物足りないように、ひらがなの絵のページが大人のご本人に合うかどうかは、人によって違います。「5歳の子にも分かるように」という名前でも、kazuさんの記事にあるとおり、狙いは「専門の知識がない人にも分かる形に組み替える」ことです。**渡す前に、その人に合う言葉と絵かどうかを、支援者が確かめます。** 漢字のほうが読みやすい人には、「漢字にふりがなを付けて」と一言足して作り直してもらえます。

## 6. 挿絵は、原典の代わりにならない

ELI5 がくれるのは、全体をつかむための挿絵です。細かい決まりや例外までは描かれていません。kazuさんの記事でも、向かない使い方として「正確な仕様や数値を確認したい」「法律、医療、金融などの重要な判断をしたい」が挙げられています。

今回のページの一番下には、「しえん する かたへ」という支援者向けの一段落も付いていました。

根拠として、障害者権利条約の第12条と、厚生労働省の意思決定支援ガイドライン（2017年）の名前が出てきます。これも AI の答えです。研修の資料や、ご家族への説明に使うなら、**条文の名前や年は、原典を開いて確かめてから**使ってください。絵が分かりやすいほど、中身まで正しく見えてしまうからです。<a href="/ai-tips/2026-07-28-ai-confidently-wrong/">AIは、自信満々にまちがえる</a>話は、あんしん編にあります。

もう一つ。題材に、特定の利用者さんの名前や様子を書き込まないでください。今回の一行も、意思決定支援という一般的な話だけで頼んでいます。どこまで話してよいかの線引きは、<a href="/ai-tips/2026-07-28-ai-privacy-line/">AIに話していいこと、いけないこと</a>の回に書いてあります。

## 7. カードがなくても、同じことは頼める

ELI5 のカードは Claude Code 用です。けれど、カードの中身は一文の頼み方なので、カードを入れていない AI にも、その一文をそのまま渡せば同じ形で頼めます。Thariq さんが紹介のポストに書いていた一文は、これです。

<div class="ai-prompt">
  <span class="ai-prompt__label">ELI5 の中身の一文（Thariq さんのポストより）</span>
  explain like I'm someone who knows nothing about this topic, using a HTML artifact with big pictures and few words
</div>

日本語にすると「この話題について何も知らない人に説明するつもりで、大きな絵と少ない言葉を使った HTML のページで説明して」。英語のままでも日本語にしても、AI には通じます。

私の一行を、カードなしで頼むならこうなります。

<div class="ai-prompt">
  <span class="ai-prompt__label">カードがないときの頼み方（今回の例）</span>
  知的障害のある人への意思決定支援について説明してください。この分野をまったく知らない人に向けて、大きな絵と、とても少ない言葉で、1枚のページ（HTML）にしてください。文章だけで説明せず、絵を3枚以上入れてください。<br>
  必ず入れてほしいこと：自分のことを決めるのは私の権利であること。そのことは相手に言えること。
</div>

組み立ては三つです。一つ目が「何についての話か」。二つ目が ELI5 の中身にあたる「何も知らない人に、大きな絵と少ない言葉で、1枚のページに」。三つ目が「必ず入れてほしいこと」です。「絵を3枚以上」は、kazuさんの記事にあったコツです。図が出てこないときは、この一言を足すと出やすくなるそうです。

送る先は、答えをページの形で表示できる AI にします。Claude なら、claude.ai やアプリにそのまま送ればページが表示されます。Gemini も、モデルに Carbon を選んでいれば、別の画面を開かなくても、「絵を入れて」の一言でページを作ってくれました（2026年11月時点）。毎回打つのが面倒になったら、二つ目の部分を「スキル」として覚えさせておきます。Gemini も、これまでの Gem に代わってスキルを使う形になりました（「カスタマイズ」→「スキル」）。覚えさせたスキルが、ELI5 のカードの代わりになります。

この文例を、Gemini でも試してみました。文章は打たずに、上の依頼文の画面写真を貼っただけです。Gemini は写真の中の文字を読み取り、右側にページを作りました（写真で頼むやり方は<a href="/ai-tips/2026-08-20-ai-photo-first/">文字にする前に、写真で見せる</a>の回にあります）。

同じ頼み方でも、ずいぶん違うページが返ってきました。ELI5 はひらがなで書きましたが、Gemini は漢字にふりがなを振る書き方です。大きな見出しは「自分のことを 決めるのは、私です。」で、「私」の一字だけが赤く、波線で強調されています。上には「ぜんぶ 声で聞く」「ふりがな ON/OFF」「印刷する」のボタンも並びました。文字を読むのが苦手な人には声で、紙で渡したい人には印刷で、という気の配り方です。どれも、私の依頼文には書いていません。

ルーの銘柄を替えると、同じ具でも味が変わります。どちらが正しいという話ではありません。目の前の人に合うほうを選び、足りないところは「漢字にふりがなを付けて」「声で読み上げるボタンを付けて」と、一言足して作り直してもらえばよいのです。

## 8. 今日ためすなら

まずは、カードを入れずに、7 の頼み方で試してみてください。最初の「何についての話か」と、最後の「必ず入れてほしいこと」を、自分の題材に入れ替えるだけです。

肝心なのは、最後の「必ず入れてほしいこと」です。ここに、現場の人として外してほしくない一点を書きます。

試しやすいテーマを、いくつか挙げておきます。どれも、細かい話に入る前に、まず全体を絵で見ておきたくなる話です。

- 障害福祉サービスを使い始めるまでの流れ（相談から、利用が始まるまで）
- 成年後見と任意後見の違い
- AI が自信満々にまちがえるのはなぜか（AI は、次に来そうな言葉を選んで文を作っています）
- AI の「手足」になる道具、MCP のしくみ

挿絵で全体をつかんでから原典やガイドラインを読むと、いま読んでいるところが全体のどこに当たるのかが分かります。
