## 見えてきたこと、4つ

### 1. 検索できるだけで、誤りは消えた

Geminiの答えにあった3つの誤り（受取口座、現況届、遺族年金）は、検索できる B・C・D のどれにも出てきませんでした。とくに、いちばん危なかった遺族年金の「20歳未満まで」は、3つとも正しく書いています。

ただし、誤りが消えたのは、検索が「正解を書いてくれた」からだけではありません。B と D は、受取口座や現況届に**そもそも触れていません**。書かなければ、まちがえようもない。答え合わせ表の「―」も、読むときの大事な手がかりです。

### 2. 「知っていること」が効く

C の答えは、質問した人の名前への呼びかけで始まりました（この記事では名前を黒塗りにしています）。AIのメモリが、質問した人のことや、福祉と法律にくわしいことを覚えていたのです。

そのぶん、答えは深くなりました。兄弟が後見人になると、同じ相続人どうしで利益がぶつかること。親が受け取りそこねた年金（未支給年金）を、子が請求できること。扶養共済の年金は、生活保護の収入として数えないこと。最後には「家族向けの説明資料にする予定でしたら、1枚ものにしましょうか」という申し出までありました。

ただ、出典は民間の社会保険労務士のサイト3件でした。**道具は持っていても、使われていなかった**のです。

### 3. 一言で、道具が目を覚ます

C と D は、同じ会話です。違いは、たった一言だけ。

この一言で、AIは法律の条文を調べる道具を呼び出しました。答えは、こう変わりました。

- **出典**：民間のサイト3件 → 法律の条文（e-Gov）と、日本年金機構・厚生労働省・国税庁の資料
- **新しく出てきたこと**：年金は差し押さえが禁止されていること。親と暮らしていた子が受け取れる場合がある「死亡一時金」。20歳前の障害の所得制限の、具体的な金額
- **分からないことを、分からないと言う**：生活保護の運用や、グループホームの家賃補助の細かい要件は、「確かめていない」とはっきり書きました
- **自分の誤りを、自分で直す**：C で「住民税非課税などの所得要件」と書いたところを、「規則を確かめずに書いたものでした」と撤回しました

この回でいちばん大事な発見は、これかもしれません。**道具を持ったAIが一番変わったのは、「知らないことを、知らないと言えるようになった」ことでした**。赤ペンが減るのは、正しいことを言うからだけではありません。まちがったことを言わなくなるからです。

### 4. それでも、最後まで残った赤ペン

4つの答えすべてに、赤ペンが残りました。

## ひとことで言うと

**道具で、赤ペンは減る。頼み方で、もっと減る。それでも最後の赤ペンは、制度の「いま」と、暮らしを知っている人が持つ。**

## 4つの答え（全文・原文のまま）

文章は原文のままです（見出しや太字などの書式だけ、読みやすく整えています）。Geminiの答えは、[第1回](/ai-tips/2026-09-23-akapen-1-oyanakiato-nenkin/)に全文を載せています。

<summary>B：検索（Claude・シークレットチャット）</summary>
<div class="akapen-full__body">
<p>障害のあるお子さんの年金とお金について、今年度の金額を確認してからまとめます。<strong>結論から言うと、お子さん本人の障害年金は親が亡くなっても止まりません。</strong> 本当に問題になるのは「お金が入るかどうか」より、「誰がそのお金を管理するか」と「親の財産をどう渡すか」です。</p>
<p><strong>1. 本人の年金・手当はそのまま続く</strong></p>
<p>障害基礎年金はお子さん本人の権利なので、親の死亡とは無関係に支給が続きます。今年度（令和8年4月時点）の金額は月額で1級が88,260円、2級が70,608円です。重度の方は特別障害者手当（月30,450円）も在宅であれば年金と一緒に受け取れ、ただし所得制限があります。</p>
<p>注意点として、知的障害の多くは「20歳前に初診日がある」扱いになり、この場合は本人の所得制限がかかります。親の財産を相続しても「所得」ではないので通常は影響しませんが、相続した財産から家賃収入や配当が出る場合は確認が必要です。</p>
<p><strong>2. 親の死亡で「増える」可能性があるもの</strong></p>
<ul>
<li><strong>遺族年金</strong>：お子さんが20歳未満で障害等級1・2級なら遺族年金の「子」に当たります。<strong>20歳以上になっていると原則対象外</strong>です。対象になっても障害年金とは基本的にどちらか一方を選ぶ形になります。</li>
<li><strong>心身障害者扶養共済（しょうがい者扶養共済）</strong>：親が生前に加入していれば、親の死亡後、お子さんに1口あたり月2万円が終身で支給されます。これは親亡き後対策として最も確実な仕組みの一つです。</li>
</ul>
<p><strong>3. 相続でつまずきやすい点</strong></p>
<p>お子さんは法定相続人です。ただ、遺産分割協議には判断能力が必要なため、<strong>知的障害の程度によっては成年後見人を立てないと手続きが止まります</strong>。後見人は原則として一生続き、専門職が就けば報酬もかかります。これを避けるには、<strong>親が遺言書（できれば公正証書）を残しておく</strong>のが最も効果的です。</p>

<details class="akapen-full">
<summary>C：ふだん（Claude・ふつうのチャット）</summary>
<div class="akapen-full__body">
<p><span class="akapen-redact" aria-label="名前は伏せています">■■</span>さん、ポイントは「本人の障害年金は親の死亡後も変わらず続くが、親の遺族年金は原則として子には出ない。そのうえで、入ってくるお金を誰が管理するかが最大の問題になる」という点です。</p>
<p><strong>1. 本人の障害基礎年金は続く</strong></p>
<p>障害基礎年金は本人の受給権なので、親が亡くなっても金額も支給も変わりません。参考までに、令和8年度は1級が年額1,059,125円（月額88,260円）、2級が年額847,300円（月額70,608円）です。年金生活者支援給付金は1級で月額7,025円、2級で月額5,620円が上乗せされます（所得制限があり、別途申請が必要）。</p>
<p>注意点は2つです。</p>
<ul>
<li><strong>20歳前傷病による障害基礎年金には本人所得による支給制限がある</strong>。相続した預貯金そのものは所得ではありません。ただし、相続したアパートの家賃収入などが生じると影響する可能性があります。</li>
<li><strong>受取口座が親名義になっていないか</strong>。本人名義の口座であれば親の死亡で凍結されません。親の口座で一緒に管理していた場合は、相続財産との区別が問題になります。</li>
</ul>
<p><strong>2. 親の遺族年金は、成人した子にはほぼ出ない</strong></p>
<p>遺族基礎年金・遺族厚生年金の「子」は、18歳になった後の最初の3月31日までの子、または20歳未満で障害等級1級・2級の状態にある子に限られます。成人した知的障害のある子は、障害が重くても遺族年金の対象外です。「親の年金を引き継げる」と誤解している家族は多いので、ここは早めに伝えるべき点です。</p>
<p>ただし、親が亡くなった月までの年金で未受給の分（未支給年金）は、生計を同じくしていた子が請求できます。</p>
<p><strong>3. 親の死亡で入ってくる可能性があるお金</strong></p>
<ul>
<li><strong>心身障害者扶養共済</strong>：親が加入していれば、子に終身で1口月2万円（2口まで）が支給されます。非課税で、生活保護でも収入として扱われません。親の死亡後の定期収入としては最も確実な制度です。</li>
<li><strong>相続財産</strong>：子は法定相続人です。相続税には障害者控除があり、（85歳−相続時の年齢）×10万円、特別障害者なら20万円が差し引かれます。</li>
<li><strong>生命保険金</strong>：受取人が子に指定されていれば、遺産分割を経ずに受け取れます。</li>
</ul>
<p><strong>4. 実務上の最大の問題は「管理する人がいない」こと</strong></p>
<ul>
<li><strong>遺産分割協議</strong>：本人に判断能力がなければ協議ができず、成年後見人の選任が必要になります。後見人が兄弟など同じ相続人の場合は利益相反になるため、特別代理人や後見監督人が関わる必要があります。遺言で分け方を指定しておけば、協議そのものを避けられます。</li>
<li><strong>年金や財産の日常的な管理</strong>：親が事実上担っていた役割に、法的な裏付けのある後任がいない状態になります。障害状態確認届（更新）の提出や、共済・未支給年金の請求手続きも同じです。</li>
<li><strong>生活保護を受けている場合</strong>：相続で資産が入ると、保護の停止や廃止につながり得ます。一方、グループホームの家賃補助（特定障害者特別給付費）などは、住民税非課税などの所得要件で判断されます。資産の増加が各給付にどう影響するかは、個別に確認が必要です。</li>
</ul>
<p><strong>5. 生前にできる手当て</strong></p>
<p>遺言（できれば公正証書で）、扶養共済への加入、特定贈与信託（特別障害者は6,000万円、それ以外は3,000万円まで贈与税が非課税）、家族信託、受取人指定型の生命保険、後見人の候補者の確保、年金の口座を本人名義に整理しておくこと、などが典型です。お金の手当てだけ済ませても、管理する人を決めておかないと機能しない、というのが実務上の実感だと思います。</p>
<p>家族向けの説明資料にする予定でしたら、「遺族年金は出ない」「扶養共済は出る」「管理する人が要る」の3点に絞った1枚ものにすると伝わりやすいです。必要でしたら作ります。</p>

<p><strong>前回からの訂正</strong></p>
<ul>
<li><strong>抜け：死亡一時金。</strong> 成人した子でも、親と生計を同じくしていれば受け取れる場合があります（下の2）。</li>

</ul>
<p><strong>1. 本人の障害基礎年金は、親が亡くなっても続く</strong></p>
<ul>
<li><strong>支給の根拠：</strong> 初診日が20歳前の障害には、国民年金法30条の4で本人に支給されます。親の死亡で権利がなくなる規定はありません。</li>
<li><strong>金額：</strong> 2級は780,900円×改定率、1級はその125%です（国年法33条）。令和8年4月分から、昭和31年4月2日以後生まれの人は1級が1,059,125円、2級が847,300円です（日本年金機構）。ネット上には1級を「1,059,120円」とする誤りがあります。</li>
<li><strong>年金生活者支援給付金</strong>（支援給付金法15条）：1級は月額7,025円、2級は月額5,620円です。前年所得が4,794,000円（扶養親族1人につき38万円を加算）以下であることが条件です。</li>
<li><strong>20歳前傷病の所得制限</strong>（国年法36条の3、同施行令5条の4）：前年所得が3,761,000円を超えると半額、4,794,000円を超えると全額が止まります。扶養親族がいれば基準額が上がり、停止期間は10月から翌年9月までです。</li>
<li>判定に使う所得は住民税の総所得金額等です（施行令6条・6条の2）。相続で取得した財産は所得税の非課税所得です（所得税法9条1項17号）。</li>
<li>つまり、相続した預金そのものでは停止されません。問題になるのは、相続したアパートの家賃のように財産から生じる所得です。住民税側の条文（地方税法）は【未照合】です。</li>
<li><strong>受給権の保護：</strong> 譲渡・担保・差押えは禁止されており（国年法24条）、税金などの公課もかかりません（25条）。</li>

<p><strong>3. 障害者扶養共済（しょうがい共済）</strong></p>
<ul>
<li><strong>支給額：</strong> 保護者が死亡するか重度障害になると、1口月2万円（2口で4万円）が生涯支給されます（厚労省「案内の手引き」令和6年10月版）。</li>
<li><strong>実施主体：</strong> 都道府県と指定都市です。北九州市は指定都市なので、北九州市の制度です。</li>
<li><strong>税金：</strong> 所得税はかかりません（所得税法9条1項3号ハ）。受給権は相続税の課税価格にも入りません（相続税法12条1項5号）。</li>
<li><strong>生活保護：</strong> 収入として認定されません（手引き）。</li>
<li><strong>年金管理者：</strong> あらかじめ指定できます。5の「お金を管理する人がいない」問題に対して、制度の中で打てる手です。</li>
</ul>
<p><strong>4. 相続と税</strong></p>
<ul>
<li><strong>障害者控除</strong>（相続税法19条の4）：障害者である法定相続人の相続税から、85歳になるまでの年数×10万円（特別障害者は20万円）を差し引きます。1年未満の端数は1年に切り上げます。</li>
<li>本人の税額から引き切れない分は、扶養義務者の相続税から差し引けます（同条3項で19条の3を準用、国税庁タックスアンサーNo.4167）。</li>
<li>知的障害者と判定された人は障害者に当たり（相続税法施行令4条の4、所得税法施行令10条1項1号）、重度なら特別障害者です（所得税法施行令10条2項）。</li>
<li><strong>生命保険金の非課税枠</strong>（相続税法12条1項6号）：500万円×法定相続人の数です。</li>
<li><strong>特定贈与信託</strong>（相続税法21条の4）：親が生前に信託銀行などと契約して財産を託す場合の<strong>贈与税</strong>の非課税です。非課税枠は特別障害者が6,000万円、それ以外の特定障害者が3,000万円です。知的障害と判定された人は3,000万円枠の対象に入ります（相続税法施行令4条の8、所得税法施行令10条1項1号）。受託者との契約が要件なので、親が亡くなってから使う制度ではありません。</li>
</ul>
<p><strong>5. お金を管理する人の問題</strong></p>
<ul>
<li><strong>遺言：</strong> 遺言で遺産の分け方を指定しておけます（民法908条1項）。そうすれば、判断能力のない本人を交えた遺産分割協議を避けられます。</li>
<li><strong>利益相反：</strong> 後見人と本人の利益がぶつかる場合、たとえば兄弟が後見人で、自分も相続人として遺産分割に加わる場合は、826条が準用され、特別代理人の選任が必要です（民法860条）。後見監督人がいれば特別代理人は要らず、監督人が本人を代表します（851条4号）。</li>
<li><strong>生活保護：</strong> 保護は、使える資産を生活のために活用することが要件です（生活保護法4条1項）。お金があるのに保護を受けた場合は、その分を返す義務があります（63条）。</li>
<li>相続で資産が入ったときに保護が停止・廃止されるのか、63条の返還をいつから数えるのかといった運用は、保護の実施要領を確認していないので【未照合】です。</li>
<li><strong>グループホームの家賃補助</strong>（特定障害者特別給付費、障害者総合支援法34条）：法律上の対象は「所得の状況その他の事情をしん酌して主務省令で定めるもの」です。前回「住民税非課税などの所得要件」と書いたのは、省令を確かめずに書いたものでした。省令の具体的な要件は【未照合】です。</li>
</ul>
