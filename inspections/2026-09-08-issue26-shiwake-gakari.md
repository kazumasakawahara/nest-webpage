## 6. 差し戻し文（不備があった場合のみ・修正はしない）
- **どこが**: `public/downloads/shiwake-gakari-v1.0.zip` のディレクトリエントリ `shiwake-gakari/` と `shiwake-gakari/templates/`
- **どの基準に**: Issue #26 完了条件「zip を展開して読める」
- **どう反するか**: ディレクトリエントリの external_attr が `0600`（`0o40755` ではない）。`unzip` で展開したフォルダに実行ビットが無く、中のファイルを読めない
- **再現手順**:
  ```
  mkdir /tmp/sg && cd /tmp/sg && unzip -q <repo>/public/downloads/shiwake-gakari-v1.0.zip && ls shiwake-gakari/templates
  → ls: shiwake-gakari/templates: Permission denied
  python3 -c "import zipfile;[print(i.filename,oct(i.external_attr>>16)) for i in zipfile.ZipFile('<repo>/public/downloads/shiwake-gakari-v1.0.zip').infolist()]"
  → shiwake-gakari/ 0o600 ／ shiwake-gakari/templates/ 0o600
  ```
- **直し方の指定（作業者向け）**: zipfile で書くなら、ディレクトリの `ZipInfo` に `external_attr = (0o40755 << 16) | 0x10`、ファイルに `external_attr = 0o100644 << 16` を明示する。または `cd` して `zip -r` で作り、日本語名は `-UN=UTF8` 相当の扱いになるかを `zipfile` の `flag_bits & 0x800` で再確認する。作り直したら A7 と B1 だけ再検品（r2）。
