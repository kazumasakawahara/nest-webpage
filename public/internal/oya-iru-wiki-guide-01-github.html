くわしい手順書 ①　テンプレートを手に入れる

日記からつくる、わが子のバイブル（oya-iru-wiki）／ くわしい手順書 全5冊の1冊目

この手順書は、ダウンロードしたファイルの扱いに慣れていない方のためのものです。 登録も費用も要りません。やることは「ZIP ファイルを1つダウンロードして、決めた場所に置く」だけです。

所要時間: 5〜10分 ／ 前の手順: なし（ここが最初です） ／ 次の手順: ② Obsidian を入れて、Vault として開く

1. ダウンロードする

nest のサイトの「親なき後」ページにある、「テンプレートをダウンロード（無料・ZIP）」のボタンを押してください。押すとすぐにダウンロードが始まります。数MB、数秒です。

うまくいかないときや、この手順書を印刷して読んでいる方は、ブラウザで次のアドレスを直接開いても同じものが落ちてきます。

https://github.com/kazumasakawahara/oya-iru-wiki/archive/refs/heads/main.zip

どこから配られているのか。 このテンプレートは GitHub という公開の棚に置いてあり、誰でも・無料で・登録なしに持ち帰れます。上のボタンは、その棚から ZIP を直接取ってくるだけの近道です。棚そのものを見たい方は方法Bへ。

2. ZIP を展開する

  • Mac: ダウンロードフォルダの oya-iru-wiki-main.zip をダブルクリックすると、oya-iru-wiki-main というフォルダができます
  • Windows: oya-iru-wiki-main.zip を右クリック → 「すべて展開」を選びます

ここでつまずく方が多いポイント: Windows では、ZIP をダブルクリックすると「中をのぞいている」だけの状態になります。見た目はフォルダですが、まだ展開されていません。必ず右クリック → すべて展開をしてください。

3. 置き場所に移す

展開してできたフォルダを、ホームフォルダの下の Obsidian フォルダに移します（Obsidian フォルダがなければ作ってください）。

  • Mac の例: /Users/あなたの名前/Obsidian/oya-iru-wiki
  • Windows の例: C:\Users\あなたの名前\Obsidian\oya-iru-wiki

移すときに、フォルダ名の末尾の -main は消して oya-iru-wiki にしておくと、この後の説明とそろって迷いません。

なぜ「書類」や「デスクトップ」ではだめなのか。 だめではありません。ただ、クラウド同期（iCloud・OneDrive）が自動で効くフォルダに置くと、お子さんの記録がクラウドに上がります。それを承知で選ぶのでない限り、同期対象でない場所（ホーム直下の Obsidian フォルダなど）をおすすめします。

書類を入れる受付箱のほうは、逆にクラウドの中に作ります（⑤）。記録の本体は同期させない、書類の入口だけ同期させる——という使い分けです。

4. できたかどうかの確かめ

フォルダを開いて、中に README.md purpose.md 記入例 などが見えれば成功です。これでこの手順書は終わりです。② Obsidian を入れて、Vault として開く へ進んでください。

ZIP で入れた場合、あとで一度だけ「実行の許可」を戻す作業があります（④ 黒い画面をこわがらない で説明します）。今は気にしなくて大丈夫です。

方法B: GitHub の画面から入手する

配布元の棚を自分の目で見てから持ち帰りたい方へ。ブラウザで次を開きます。

https://github.com/kazumasakawahara/oya-iru-wiki

英語まじりの画面が出ますが、読む必要はありません。ファイルの一覧が並んでいれば正しいページです。緑色の「Code」ボタン →メニューのいちばん下の 「Download ZIP」 で、1と同じ ZIP が落ちてきます。あとは2以降と同じです。

見た目が変わっていて緑のボタンが見つからないときは、そのページの URL を AI に伝えて「このページから ZIP をダウンロードする場所を教えて」と聞いてください。

方法C: Git でクローンする（Git を使ったことがある方向け）

Git が入っているパソコンなら、ターミナルで次を実行します。

git clone https://github.com/kazumasakawahara/oya-iru-wiki.git ~/Obsidian/oya-iru-wiki
  • クローンなら、後で「実行の許可」を戻す作業は不要です
  • 実データの運用を始める前に、公開への道を断つ（git remote remove origin）ことを忘れないでください（導入手順.md Step 1）
  • 「Git って何？」という方は、方法A で何も問題ありません。Git は履歴を残したい人向けの追加の道具です

よくあるつまずき

症状 対処
ダウンロードした ZIP が見つからない ブラウザの「ダウンロード」フォルダを見る（Mac: Dock の右端／Windows: エクスプローラーの「ダウンロード」）
「このファイルは安全でない可能性があります」と出た この ZIP は一般的な配布方法で配られています。「保存」「継続」を選んで大丈夫です。不安なら、落ちてきたファイル名が oya-iru-wiki-main.zip であることを確かめてください
フォルダの中に同じ名前のフォルダがもう一段ある 展開のしかたによって起きます。内側の（README.md が直接見える方の）フォルダを置き場所に移してください
ボタンを押しても何も起きない ブラウザがダウンロードをブロックしていることがあります。上の直接アドレスをアドレス欄に貼って開いてください
