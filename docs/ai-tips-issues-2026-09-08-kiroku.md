## #26 仕分け係スキル（配布zip）の作成と実演セットでの実験 E2

## 概要

読者に配る **仕分け係（shiwake-gakari）** を作り、架空の旅の材料で一周させて、手順書が働くか確かめる（実験 E2）。仕様は企画書の付録A（SKILL.md 下書き）・付録B（テンプレート3枚）・付録C（実演セット）に書き切ってある：`docs/ai-tips-series-proposal-2026-09-08-kiroku.md`。親 Issue：#24

## やること

1. **配布 zip** `public/downloads/shiwake-gakari-v1.0.zip`（倉庫番 `souko-ban-v1.0.zip` と同じ構成）
   ```
   shiwake-gakari/
   ├─ SKILL.md            付録A の本文（frontmatter の name は shiwake-gakari）
   ├─ templates/
   │   ├─ 写真の記録.md
   │   ├─ 録音の記録.md
   │   └─ 一行の記録.md   付録B
   ├─ README.md           倉庫番の README と同じ体裁（同梱物・必要なもの・入れ方・スマホ側のコツ）
   └─ LICENSE             CC BY 4.0（倉庫番の LICENSE の名前を差し替え）
   ```
2. **実演セット** `docs/kiroku-demo/記録/`（すべて架空。コミットしてよい）
   - `raw/2026-08-10 潮見町.md`（付録C の本文）＋ 写真3枚 `IMG_0412.jpg` `IMG_0418.jpg` `IMG_0431.jpg`（フリー素材か、単色に簡単な図形を描いた仮の画像でよい。人が写っていないもの）
   - `_テンプレート/` に付録B の3枚
   - `日々/` `ページ/` は作らない（仕分け係に作らせる）
3. **実験 E2**：Claude（Claude Code か Claude Desktop＋Filesystem）に SKILL.md を読ませ、実演セットに対して「raw の新しいものを仕分けて」と頼む
   - AI の返事（4行の報告を含む）を **無加工で** `docs/kiroku-demo/log-E2.md` に残す（日付・使ったモデル名を添える）
   - 作られた `日々/` `ページ/` もそのままコミット
   - 手順書の不備が見つかったら SKILL.md を直し、直した点を log に書く（返事のほうは直さない）

## 見るところ（完了条件）

- `raw/` の中身が **1バイトも変わっていない**（`git diff --stat docs/kiroku-demo/記録/raw` が空）
- `日々/` に写真1枚につき1ノート（3枚）。frontmatter が `date / kind / about / place / source` で、`source` が raw のファイル名を指す
- `ページ/` に「潮見町」「岬の灯台」「浜食堂」など、本文の言葉そのままの名前でページが立ち、中身は一行の説明＋初出の日付だけ
- ノート本文の一言が **書き足されていない**（一字一句、raw と同じ）
- 「おかみさん」のページが **作られていない**（人のページは本人と家族・友人だけ）
- 報告が4行の型どおり
- zip を展開して読める（`unzip -l` で4階層が出る）
- **push はしない**

## 材料を足す（実演セットの拡張。すべて架空）

## 試すこと（並走してよい）

| 案 | 作るもの | 見るところ |
