# イベントの告知から開催報告まで（nest News）

音楽会、落語、研修会など、nest が開くイベントを nest News に載せるときの手順です。種類が違っても手順は同じで、違うのは `tag`（研修会かどうか）だけです。
秋の音楽会（2026-10-17）の告知・満席・開催報告の流れを型にしました。

流れは三回の更新でできています。

1. **告知**（チラシが届いたら）
2. **満席**（定員に達したら。満席にならなければ飛ばす）
3. **開催報告**（終わってから、写真が届いたら）

告知に開催日を書いておけば、開催日の翌日から記事に「終了」が出ます。報告を載せれば、告知の冒頭に「開催報告を掲載しました」と報告へのリンクが出ます。告知の本文を後から書き換える必要はありません。

---

## 河原さんから Claude への依頼文の型

コピーして、〔 〕の中だけ書き換えてください。足りないものがあれば Claude から聞き返します。

### 1. 告知

```
nest News にイベントの告知を載せてください。
チラシ：〔PDF や画像を添付／Drive のファイル名〕
主催：〔nest／木町家／ほかの団体（日本財団など）〕
補足：〔チラシにないこと、変えたいこと。なければ「なし」〕
```

### 2. 満席

```
〔イベント名〕が満席になりました。nest News の告知を満席にしてください。
```

### 3. 開催報告

```
〔イベント名〕の開催報告を nest News に載せてください。
写真：〔添付〕
当日のようす：〔何人来たか、印象に残った場面、反応。箇条書きでかまいません〕
写真のお顔：〔お客さま・参加者の顔はぼかす／そのまま（掲載の了解あり）〕
```

## Claude（または作業する人）がすること

### 1. 告知

- 記事ファイル：`src/content/news/<掲載日>-<英字の短い名前>.md`
- frontmatter（[テンプレート](#告知のテンプレート)）
  - `tag`：nest や木町家が開く音楽会・落語などは `イベント`。nest が開く研修会は `研修会`（参加者を募る案内は `showInNews: true` も）。**ほかの団体が主催するものは研修会にしない**（研修会コーナーは「nestが開催した研修会」のため。2026-10-06 の日本財団セミナーで河原さんが指摘）
  - `eventDate`：**開催日を必ず書く**。複数日にわたるときは最終日
- チラシ
  - PDF は `public/pdfs/notices/` に置き、本文の末尾からリンク
  - 記事に見せる画像は JPG にして `public/images/` に置く（`pdftoppm -jpeg -r 150` など。幅 850〜1414px、1 枚 500KB 以内を目安に）
- 本文：チラシの文言をそのまま写さず、日時・会場・料金・定員・申し込み方法を拾って読みやすく。曜日はカレンダーで検算する。メールとチラシで食い違うところはチラシに合わせ、河原さんに伝える

### 2. 満席

- 告知の frontmatter に `soldOut: true` を足すだけ。一覧の題名の頭と記事ページの冒頭に「満席」が出る
- 本文の「お申し込み方法」の頭に `**※ 満席のため、受付は終了しました。**` を一行足す

### 3. 開催報告

- 記事ファイル：`src/content/news/<掲載日>-<告知と同じ英字の名前>-report.md`
- `tag` は告知と同じにする（研修会の報告は `研修会` で、研修会コーナーに並ぶ）
- frontmatter に `reportOf: <告知記事のファイル名から .md を除いたもの>` を書く。これで告知の冒頭に報告への案内が出る（書き間違えると `npx vitest run` が落ちる）
- 写真
  - 長い辺 1600px の webp にして `public/images/news/` へ（`<掲載日>-<名前>-1.webp` …）
  - **お客さま・参加者のお顔が判別できるものはぼかす**（横顔・正面）。出演者・演者・講師で、告知にも顔写真を出している方はそのまま。ぼかしたら本文に「写真は、お客さまのお顔がわからないよう加工しています。」と書く
  - 利用者さんが写っているときは、掲載してよいかを必ず河原さんに確かめる
  - `alt` には写っているものを具体的に書く
- 本文
  - 河原さんから聞いたことの範囲で書く。曲名や当日の場面など、聞いていないことは書かない
  - 最後に、告知記事と、次に予定しているイベントがあればその告知へのリンクを置く

### 公開まで

- `npm run build` と `npx vitest run` が通ること
- ブランチを切って draft の PR を出し、河原さんの確認を待つ。「公開して」でマージ
- `タスク.md` と `作業ログ.md` に記録する

## 画面に出るもの

| 告知の状態 | 一覧の題名の頭 | 告知の記事ページの冒頭 |
|---|---|---|
| 開催前 | なし | なし |
| 開催前・満席 | 「満席」 | 「満席」と「満席となりました」の囲み |
| 開催日の翌日から | 「終了」 | 「終了」と「このイベントは終了しました」の囲み |
| 開催報告を載せた後 | 「終了」 | 「終了」と「開催報告を掲載しました」の囲み（報告へのリンク） |

サイトは載せた時点で作られるので、開催日を過ぎても作り直しがなければ古いままになります。そのため「終了」への切り替えは、読む人のブラウザでも日付を見て行っています（`src/layouts/BaseLayout.astro` の末尾）。判定は `src/lib/event-news.ts`、開催日の翌日 0 時（日本時間）からが「終了」です。

`eventDate` を書いていない 2026-10-21 より前の記事は、これまでどおり満席かどうかだけで表示が決まります。

## テンプレート

### 告知のテンプレート

```markdown
---
title: 〔イベント名〕（〔月〕月〔日〕日）のご案内
date: 〔掲載日 YYYY-MM-DD〕
tag: イベント
eventDate: 〔開催日 YYYY-MM-DD〕
summary: 〔一覧とSNSに出る一文。いつ・どこで・何を・定員〕
image: /images/〔チラシ画像〕.jpg
---

〔書き出しの一、二文〕

**〔YYYY〕年〔M〕月〔D〕日（〔曜〕）**、〔会場〕で〔イベント名〕を開催します。

<div class="news-gallery">
  <figure>
    <img src="/images/〔チラシ画像〕.jpg" alt="〔チラシに写っているもの〕" width="〔幅〕" height="〔高さ〕" loading="lazy" decoding="async" />
    <figcaption>チラシ（PDF版は文末のリンクからどうぞ）</figcaption>
  </figure>
</div>

## 開催概要

- **日時**：
- **会場**：
- **料金**：
- **定員**：

## お申し込み方法

〔申し込み方法と問い合わせ先〕

- [チラシ（PDF）](/pdfs/notices/〔ファイル名〕.pdf)
```

### 開催報告のテンプレート

```markdown
---
title: 〔イベント名〕を開催しました
date: 〔掲載日 YYYY-MM-DD〕
tag: イベント
reportOf: 〔告知記事のファイル名から .md を除いたもの〕
summary: 〔いつ・どこで開いたか、いちばん伝えたい当日のようすを一文で〕
image: /images/news/〔掲載日〕-〔名前〕-1.webp
---

〔いつ、どこで開いたか。来てくださった方へのお礼〕

<div class="news-gallery">
  <figure>
    <img src="/images/news/〔掲載日〕-〔名前〕-1.webp" alt="〔写っているもの〕" width="1600" height="1200" loading="lazy" decoding="async" />
    <figcaption>〔短い説明〕</figcaption>
  </figure>
</div>

写真は、お客さまのお顔がわからないよう加工しています。

〔当日のようす。聞いたことの範囲で〕

- ご案内の記事：[〔告知の題名〕](/news/〔告知記事のファイル名〕/)
```
