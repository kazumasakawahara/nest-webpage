# 公式サイト評価（nponest.com）— 2026-09-25

対象：本番サイト https://nponest.com/ （トップページを中心に、サイトマップ全113ページを機械チェック）
方法：内蔵ブラウザで PC 幅（1280px）・スマホ幅（375px）を目視、JS でコントラスト・タップ領域・読み込み量を計測、curl で全ページの応答・内部リンク・title/description を確認。
コードは変更していない（指摘のみ）。

---

## 総評

温かいエディトリアルの世界観（巣箱の写真・明朝・クリーム×緑×テラコッタ）はよく出来ていて、「巣立っても、いつでも帰ってこられる。」という一行で法人の性格が伝わる。スマホ下部の「お電話／見学・お問い合わせ」固定バー、横スクロールなし、全ページ alt あり、内部リンク切れ 0 件と、基礎体力は高い。

伸びしろは次の3つにまとまる。
1. **重さ**：トップページの読み込みが約 22MB。スマホ回線では最初の表示が遅く、見学を考えている家族が離れる原因になる。
2. **情報の食い違い・古さ**：対象者の書き方、設立年数、事業の数などがページや箇所によって違う。
3. **家族が知りたい情報の不足**：利用者募集・グループホームのページに、対象・費用・空き・利用の流れといった判断材料が少ない。

## 良い点（維持したいところ）

- **一行で伝わる**：「巣立っても、いつでも帰ってこられる。」と巣箱の写真で、法人の姿勢が2秒で伝わる。
- **スマホの問い合わせ導線**：画面下に「お電話／見学・お問い合わせ」が常に出ていて、どこからでも連絡できる。
- **基礎がしっかりしている**：全113ページが正常に表示、内部リンク切れ 0、title の重複 0、画像はすべて alt あり、横スクロールなし、`prefers-reduced-motion` への配慮あり。
- **本文が読みやすい**：スマホで本文 18px・行間 1.9。
- **グループホームの理念が具体的**：「施設に集めず、町内に点在する住まいで」という説明は他法人との違いがよくわかる。
