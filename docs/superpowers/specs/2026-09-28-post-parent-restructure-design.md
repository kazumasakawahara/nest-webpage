# 「親なき後」ページ 構成見直し 設計書

- 作成日: 2026-09-28
- 状態: 設計確定（河原さん承認済み：「この構成で設計書を書いてください」）→ 実装計画待ち
- 対象: `src/pages/post-parent.astro`（`/post-parent/`）
- 関連: 「私の想い」コーナー（`2026-09-28-watashi-no-omoi-design.md`）と同じブランチで進め、両方まとめて公開する

## 1. 目的

縦に長い1ページに9つのブロックが並び、家族向けと支援者向けの話が交互に出てくる今の構成を、**目次と4つの章**に整理して読みやすくする。

- 読者が、自分に関係のある所へ迷わず行ける
- 不安を抱えて来た親御さんが「考えに触れる → 同じ立場の声を聴く → 自分にできる備えを知る → もっと深く・つながる」の順に進める（共感を先に、実用を後に）

## 2. 決定事項

| 項目 | 決定 | 理由 |
|---|---|---|
| 主な読者 | ご家族。支援者には目次で道を1本示す | ページの芯（親が遺すべきもの）、税の話・私の想い・バイブルは家族向け |
| ページの分け方 | 1ページのまま（子ページに分けない） | ヒーローで「税の話はおまけ」と言っている流れを保つ。目次があれば長さは問題にならない |
| 目次 | ヒーローの直後に一度だけ置く。画面上部への固定はしない | スマホで固定表示が画面を狭めるため |
| 本文 | 変えない | 今回は並び・見出しの階層・目次・章の区切りだけ。文章の手直しは別の依頼 |
| ページ内リンクの位置 | `#tax`・`#column`・`#omoi` を維持 | News の記事（`#tax`）と寄稿の記事ページ（`#column`）から既にリンクされている |

## 3. 新しい構成

| 順 | 章（h2） | ページ内の位置 | 入れる中身（今のブロックを移す） |
|---|---|---|---|
| — | ヒーロー | — | そのまま |
| — | 目次「このページの内容」 | `#toc` | §4 |
| 1 | わたしたちの考え | `#belief` | ①お金より、遺すべきものがある（理念。寄稿は第2章へ出す）②「親なき後」を希望に変える（15年の取り組み・ネットワーク図） |
| 2 | 声を聴く | `#voices` | ①私の想い（`#omoi`）②寄稿（`#column`。理念の中から独立させる） |
| 3 | いま、備える | `#prepare` | ①知恵を、引き継げる形に（段落の順番は今のまま）②とはいえ、知っておきたい税の話（`#tax`） |
| 4 | 資料とつながり | `#connect` | ①知恵と仕組みを、分かち合う（資料室・ツール・研修の入口）②ゆるく、つながる（お知らせ登録） |
| — | お問い合わせ（CTA） | — | そのまま |

- 第2章は、私の想いが0件でも寄稿があるので空にならない
- 第3章①は、当初「家族向けのバイブルの段落を先に」としていたが、**段落は並べ替えない**（2026-09-28、実装計画の作成時に修正）。バイブルの段落は「そして」で、道具の段落は「その仕組みを」で前の段落を受けており、文章を変えずに順番だけ入れ替えると意味が通らなくなるため。リンク2本は、すでに「ご家族向け → 支援者向け」の順になっている

## 4. 目次

- 見出し「このページの内容」（h2）
- 4章を番号つきで並べ、各章に一行の説明を添える：

| 番号 | 章 | 一行の説明 |
|---|---|---|
| 01 | わたしたちの考え | お金より遺すべきもの。nest の15年の歩み |
| 02 | 声を聴く | ご家族から寄せられた想いと、寄稿 |
| 03 | いま、備える | 知恵を引き継ぐ道具と、知っておきたい税の話 |
| 04 | 資料とつながり | 資料室・研修アーカイブと、お知らせの登録 |

- 目次の下に一行：「支援者の方は、03 の『3つの道具』と 04 の資料室からご覧ください。」
- 構造は `<nav aria-label="このページの目次">` の中の番号つきリスト。各項目は章へのページ内リンク
- 幅が広い画面では 2列×2段、狭い画面では1列

## 5. 章の区切り

- 各章の最初に、番号つきの区切り（例：「01」＋「わたしたちの考え」）を置く。章の見出しは h2
- 見た目：既存のデザイン方針（温かいエディトリアル、nest 緑＋クリーム＋テラコッタ）に合わせ、番号はテラコッタ、章題は明朝の大きめの文字。上下に余白を取り、章の切れ目がはっきり分かるようにする
- 章の区切りにも、目次へ戻る小さなリンク（「目次へ戻る」）を置く（長いページを行き来しやすくするため）

## 6. 見出しの階層

章を h2 にするため、既存の見出しを1段ずつ下げる。**見た目の大きさは変えない**（クラスで大きさが決まっているものはそのまま、タグ名で指定しているスタイルは新しいタグに合わせて書き換える）。

| 今 | 変更後 | 対象 |
|---|---|---|
| h1 | h1 | ヒーロー |
| — | h2 | 目次の見出し、章の見出し（新規） |
| h2 | h3 | 各ブロックの見出し（`section__title`）。第2章の寄稿の見出しもここに揃える |
| h3 | h4 | 取り組みの記事内の小見出し（`.pp-article h3`）、ネットワーク図の題、税の話の小見出し（`pp-tax__h3`）、資料カードの題（`card__title`） |
| h4 | h5 | 税の話の制度名（`.pp-tax-item h4`） |

- タグ名で指定しているスタイル `.pp-article h3` → `.pp-article h4`、`.pp-tax-item h4` → `.pp-tax-item h5` に書き換える
- 寄稿は今、理念の中の小さな欄（`pp-column__title`、h3）。第2章では独立したブロックになるので、見出しを他のブロックと同じ `section__title`（h3）にし、eyebrow「Column」はそのまま使う

## 7. 背景色

ブロックの背景（白／sand／cream）の交互の並びは、新しい並び順で隣り合うブロックが同じ色にならないように付け直す。章の区切りは、直後のブロックと同じ背景にして、章の頭として一体に見せる。

## 8. 入れないもの

- 本文の書き直し
- 画面上部に固定する目次
- 子ページへの分割（税の話の独立ページなど）
- 今どこを読んでいるかを目次で強調する仕組み

## 9. あわせて直すもの

- 「私の想い」を差し込んだときに、「ゆるいつながり」の説明コメントが私の想いの上にずれた。新しい構成で正しい位置に戻す

## 10. 検証

- `npm run build`・`npm test`・e2e（`tests/e2e/`）がすべて通る
- e2e を追加：
  - 目次に4つのリンクがあり、それぞれ `#belief`・`#voices`・`#prepare`・`#connect` を指し、その要素がページにある
  - `#tax`・`#column`・`#omoi` がページにある
  - 章の h2 が「わたしたちの考え → 声を聴く → いま、備える → 資料とつながり」の順に並ぶ
- 既存の e2e の見出しレベル指定を新しい階層に合わせる（「私の想い」は h2 → h3。`smoke.spec.ts` の「知恵と仕組みを、分かち合う」はレベル指定なしなので変更不要）
- 見出しの大きさが変わっていないこと：変更前と変更後で、主な見出し（各ブロックの題・記事内の小見出し・税の小見出しと制度名・資料カードの題）の計算後の font-size を比べて一致を確認する
- 320・375・1280px で撮影して目視：横スクロールなし、目次の並び（1列／2列×2段）、章の区切りの見え方、見出しが文節の途中で折れない
- 目次のリンクを押すと各章へ移動し、ヘッダーに隠れない（`scroll-margin-top`）
- 投稿は 0 件の状態と、架空のサンプルを置いた状態の両方で見る（サンプルは確認後に削除）
