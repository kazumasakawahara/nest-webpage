# 企画書：「AIさんのポケット」― こまりごとから、さがす

作成日: 2026-07-30 ／ 対象: 教えてAIさん ／ 状態: **河原さん承認待ち**

## 0. 骨子と権利整理

河原さん発案「ドラえもんのポケットの中」を、権利面で安全な**オリジナル企画に翻訳**する。

- **使わないもの**：「ドラえもん」の名称、キャラクター意匠（青白・丸型・鈴 等）、「四次元ポケット」「ひみつ道具」等の固有の呼び名
- **使うもの**：「困りごとを言うと、ちょうどいい道具が出てくるポケット」という**アイデアそのもの**（アイデアは著作権保護の対象外）
- ポケットの主は、当コーナーの相棒ロボ **AIさん**（緑の四角いロボ。意匠上も十分な距離がある）

ねらいは導線の補完。現在27記事＋アプリ2つが「記事の種類」（3棚）で並んでいるのに対し、
読者の入口である**「困りごと」からの逆引き**を新設する。

## 1. 名前案（どちらか選択）

- **D-2**: 👝 こまったときポケット

## 3. ポケットの中身・初期セット（12項目）

各項目は「困りごとの大ボタン」→ 押すとその場で「出てくる道具」カードが開く。
道具カード＝記事リンク（またはアプリカード）＋ひとこと＋**コピペ用の頼み方1行**（該当があるもの）。

| 困りごと | 出てくる道具 |
|----------|--------------|
| 📄 役所や保険の書類が、むずかしい | 記事「役所からの手紙、AIに読んでもらう」＋頼み方1行 |
| 😱 あやしいメール・SMSが来た | 記事「詐欺から身を守る盾」＋188の案内 |
| 🎨 チラシや掲示物の絵が、見つからない | 記事「チラシの挿絵、1行で描いてもらう」＋注文1行 |
| 🧾 レシートの山を、打ち込みたくない | 記事「レシートの山、もう手入力しない」 |
| 📝 案内文・お知らせの下書きがつらい | 記事「Gemini Canvas」 |
| 📊 スライド・資料づくりが大変 | 記事「NotebookLMで資料づくり」 |
| 🛒 買い忘れ・ついで買いが多い | アプリ「かいものチェッカー」（カード） |
| 🎒 朝の忘れ物が多い | アプリ「もちものチェッカー」（カード） |
| 📞 電話応対や面談を、練習したい | 記事「AIは“相手役”にもなれる」 |
| 📷 機械やエラー画面のことを聞ける人がいない | 記事「カメラで見せながらAIに教わる」 |

| 🙋 こんな道具、ポケットにない？ | 質問箱／お問い合わせへ（＝道具の追加注文。アプリ第二作の種にも） |

※ 新記事・新アプリを公開したら、ポケットにも1行足す運用（ページ内の対応表を1行編集するだけの作りにする）。

## 4. ページ構成（本体）

1. ヒーロー：ポケット挿絵（人形劇様式・下記）＋リード「こまりごとのボタンを押すと、道具が出てきます」
2. 困りごとボタンのグリッド（スマホ2列・大きめ。押すと該当カードへスクロール＆開く）
3. 道具カード群（記事リンク／アプリカード＋頼み方1行のコピペ枠）
4. 末尾「ポケットに見つからないとき」→ 質問箱・お問い合わせ導線
5. 教えてAIさん一覧へ戻る導線

## 5. 挿絵（人形劇様式の新作）

**「AIさんのポケット」の看板絵**：舞台中央のAIさんの緑のボディに、クリーム色の**大きな前ポケット**。
そこから「書類」「かご」「絵筆」の小さな道具札がぽんぽんと飛び出し、ガタロウさんとうた美さんが
両側で受け取っている図。サンプルラフ：`docs/ai-tips-pocket-sample.svg`（添付）。
※ 青白・丸型・鈴は使わない。四角い緑ロボ＋角ポケットで、意匠上の距離を保つ。

## 改訂1（2026-07-30・河原さんフィードバック反映）

「困りごとボタンのカタログ」はピンと来ない、とのこと。河原さんのイメージは**掛け合いの一場面**：

> botさんの大きなエプロンに「AI」という名のポケットがあって、代表のマスコットが
> 「買ってくるのを忘れちゃった！」と言うと、botさんがポケットから
> 「買い物チェッカー！」と言って道具を出す。

これを受けて**ページの見せ方を全面的に改訂**する：

- **形式**：カタログ表ではなく、**紙芝居のようなスキットの連続**にする。1つの道具＝1スキット。
  - コマ①：代表マスコットの困りごとのセリフ（「買ってくるのを忘れちゃった！」）
  - コマ②：エプロン姿のAIさんが「AI」ポケットから **「かいものチェッカー！」** と道具を取り出す
  - その直下に道具カード（記事リンク／アプリカード＋頼み方1行）
- スキットは既存の qa 吹き出し様式＋挿絵で構成し、上から読むだけで劇が進む。§3の12項目は**12本のスキット**になる
- キービジュアル（ヒーロー絵）：`ai-tips-pocket-sample.svg` を改訂版に差し替え済み
  （エプロン＋「AI」ポケットのAIさん、困る代表マスコット、飛び出す道具カード「🛒 かいものチェッカー」）
- 12スキットぶんの挿絵を毎回描くのは重いので、**挿絵はヒーロー1枚＋スキットは吹き出し劇**で開始し、
  反応が良ければ代表的なスキットから挿絵を追加する
