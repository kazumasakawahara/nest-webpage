# 教えてAIさん 質問箱 起動＆運用手順（Q&A記事化ワークフロー）

質問箱コンポーネント（`src/components/AiTipsQuestionBox.astro`）を本番稼働させ、
届いた質問を「教えてAIさん」のQ&A記事にしていくための手順書です。

## 全体像

```
[Apps Script を実行] → Googleフォーム＋回答スプレッドシートが自動生成される
        ↓ 公開URLをコピー
[AiTipsQuestionBox.astro の FORM_VIEW_URL に貼り付け] → デプロイ
        ↓
教えてAIさん一覧＋全記事の末尾に「質問を送ってみる（匿名OK）」ボックスが出現
        ↓
質問が届く → NOTIFY_EMAIL に通知メール／スプレッドシートに蓄積
        ↓
編集部（Claude＋河原さん）が匿名化してQ&A記事化 → 対応状況を更新
```

## 1. 起動手順（初回のみ・所要10分）

1. フォームを管理する Google アカウントで <https://script.google.com/> を開き「新しいプロジェクト」を作成
2. `scripts/create-ai-tips-question-form.gs` の中身を全部コピーして貼り付け（既存コードは消す）
3. `NOTIFY_EMAIL` を確認（現在は `s.kawasaki@npo-nest.com`。教えてAIさん編集担当に変えるならここを書き換え）
4. 関数 `createAiTipsQuestionForm` を選んで ▶ 実行 → 初回は権限承認
5. 実行ログ（`Ctrl + Enter`）に出る **公開URL**・**編集URL**・**回答スプレッドシートURL** を控える
6. **シークレットウィンドウで公開URLを開き、ログインなしで回答できるか必ず確認**
   - ログインを求められたら、関数 `openQuestionFormToPublic` を実行（Workspaceアカウントの既定設定対策）
7. 公開URLを `src/components/AiTipsQuestionBox.astro` の `FORM_VIEW_URL = ''` に貼り付けてデプロイ
   - これだけで一覧＋全記事に質問ボックスが表示される（空文字なら非表示のまま）

作成されるフォームの項目（設計済み・実装確認済み）:

| # | 項目 | 必須 |
|---|------|------|
| 1 | AIやパソコンについて、聞いてみたいこと・困っていること（長文） | ✅ |
| 2 | お立場（福祉の仕事／ご家族／ご本人／nest職員／その他） | |
| 3 | AIの経験（未経験〜ほぼ毎日） | |
| 4 | お名前・ニックネーム（記事では使わない旨明記済み） | |
| 5 | メールアドレス（記事化時のお知らせ希望者のみ） | |
| 6 | 記事化への同意（プライバシーポリシー参照付き） | ✅ |

送信のたびに自動で走る処理（トリガー設定済み）:
① `NOTIFY_EMAIL` へ通知メール ② 記入者への受付確認メール ③ 「対応状況」列を「未対応」に初期化

## 2. 質問→記事化の運用フロー

回答スプレッドシートには編集部管理列（**対応状況・記事化予定・掲載記事URL・メモ**）が自動追加される。

1. **受領** … 通知メールが届く。スプレッドシートで内容確認（対応状況＝未対応）
2. **選定** … 記事化するものは「記事化予定」に日付・優先度をメモ。しないものは対応状況を「見送り」に
   - 迷ったら基準は「同じ疑問を持つ読者が他にもいそうか」
3. **匿名化** … 下記ルールで質問文を書き直す（Discord #nest-webpage に原文を貼らない。
   スプレッドシート上で完結させ、Claudeには匿名化後の質問文だけを渡す）
4. **執筆** … 下のテンプレートでQ&A記事を作成（通常記事と同じ読みきり枠）
5. **公開** … デプロイ後、「掲載記事URL」に記事URLを記入し、対応状況を「記事化済み」に
6. **お知らせ** … メール記入者には記事URLを一言添えて連絡（任意・手動）

### 匿名化ルール（合言葉：「相談の中身は具体的に、人物はぼかす」）

- 名前・ニックネームは使わない（フォームでも明記済み）。「ご家族の方から」「支援のお仕事をされている方から」等のお立場だけ使う
- 事業所名・地名・サービス名の固有名詞は役割に置き換える（〇〇事業所 → お勤め先）
- 質問文はそのまま引用せず**要約して書き直す**（文体からの特定を防ぐ＋読みやすくなる、の一石二鳥）
- 珍しい状況の組み合わせは、答えに影響しない範囲でぼかす

## 3. Q&A記事テンプレート

ファイルは通常記事と同じ `src/content/ai-tips/YYYY-MM-DD-スラッグ.md`（kind未指定＝読みきり枠）。
冒頭を「質問箱に届いた質問」で始めるのがQ&A記事の型。

```markdown
---
title: （通常記事と同じ流儀。質問への答えが伝わる見出し ― 補足）
date: YYYY-MM-DD
summary: 質問箱に「〜〜」という質問が届きました。（答えの要点をひとこと）
draft: false
---

[質問箱](/ai-tips/)に、こんな質問が届きました（掲載にあたり要約し、個人がわかる部分は書き換えています）。

> **Q.** （匿名化した質問文。お立場を添える：——支援のお仕事をされている方より）

（共感のひとこと：この疑問、実は多くの方が…）

<div class="qa">
  <div class="qa__row qa__row--me">
    <div class="qa__avatar">🙂</div>
    <p class="qa__bubble">（質問を会話形式で膨らませる）</p>
  </div>
  <div class="qa__row qa__row--ai">
    <div class="qa__avatar">🤖</div>
    <p class="qa__bubble">（AIさんの答えの入口）</p>
  </div>
</div>

## （答えの本論。通常記事と同じ流儀で）

<div class="ai-prompt">
  <span class="ai-prompt__label">そのまま使えるお願い文</span>
  （コピペで試せるプロンプト）
</div>

> **ひとこと：** （締め）

あわせて読みたい：（関連記事リンク）

この記事のように、質問には記事の形でお答えしていきます。「こんなこと、パソコンやAIでできる？」というギモンは、記事末尾の質問箱からぜひどうぞ。
```

## 4. 通知先メールだけ後で変える場合

Apps Script の `NOTIFY_EMAIL` を書き換えて保存するだけ（`onAiTipsQuestionSubmit` が参照しているため、フォーム再作成・トリガー再登録は不要）。
