### 見つかった手順書の不備と、直した点（SKILL.md v1.0 に反映）

1. **`about` / `place` の書き方が手順書に無かった。** 付録B の下（企画書の地の文）には「`about: ["[[浜食堂]]"]` のように引用符つき配列で書く」とあるが、SKILL.md にもテンプレートにも書いていなかったため、AI は `about: [岬の灯台]`・`place: [潮見町]` と素の文字列で書いた。Obsidian はこれをリンクとして数えない（プロパティ経由の糸がつながらない）。
   → 作法4に1項目を追加：「frontmatter では `about` に `"[[もの・人・店]]"`、`place` に `"[[場所]]"` を引用符つきの配列で書く。`[[ ]]` と引用符がないと Obsidian がリンクとして数えない」
2. **`日々/` `ページ/` が無いときの扱いが曖昧だった。** 前提には「なければ初回に作成を提案する」とあるが、いきなり「仕分けて」と頼まれたとき、提案して待つのか作ってよいのかが書かれていない。AI は作ったうえで「このままで良いですか」と聞き、聞きたいことの1つを使った。
   → 前提に1項目を追加：「`raw/` と `_テンプレート/` があって `日々/` `ページ/` がまだ無いときは、仕分けのときに作ってよい（作ったことを報告に添える。聞いて待つ必要はない）」

返事のほうは直していない。1回目の成果物（`日々/` `ページ/`、`about` が素の文字列）は最初そのままコミットしたが、#27 がこの保管庫を土台にするため、検品を受けて v1.0 の SKILL.md による3回目の出力に差し替えた（下記）。
