## 3. 推し（決定は河原さん）

**推し：A（ノート一冊）を本命に、C（印刷版）を締めの見せ場に添える。一つに絞るなら A。**

理由：
1. 一言で出る。追加の指示0で、読者の環境（Claude Desktop＋Filesystem）でそのまま再現できる。三軸のうち「手順の少なさ」は A だけが◎
2. 本人の言葉の検証を読者自身ができる。Obsidian で 旅行記/ と 日々/ を並べて開けば、`>` の行が一字一句同じだと自分の目で確かめられる。第4回の「読者の言葉だけで書く版と、AI が地の文を足す版を並べて見せ、違いを言う」（§9-1）は、A の形が一番やりやすい（`>` の行だけ残せば「言葉だけ版」になる）
3. C は A と同じ文章を紙の体裁にしたもので、A ができれば C は「もう一手」で出る（C 自身が `.md` を先に書いてから HTML にした）。記事では A を本文で見せ、末尾に C の6ページの見開き画像を置いて「本が出てくる」を締めにするのが、手順の少なさと「へー」の両取りになる
4. B は見た目の「へー」は大きいが、Obsidian 依存で、言葉が札の中に小さく収まるため「本人の言葉が残っている」ことが読者に見えにくい。第2回（地図）の図版としては強いので、旅行記の本命ではなく第2回の看板に回す手もある
