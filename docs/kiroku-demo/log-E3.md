## 1. 三つのかたちを並走させる

- 三つとも新しいサブエージェント（会話の文脈なし）。A は本体の保管庫、B・C は同じ保管庫の複製（`raw/` `日々/` `ページ/` `_テンプレート/` を丸ごとコピー）で動かし、できたものを `記録/旅行記/` に集めた。並走中に同じファイルへ書き込む衝突を避けるため
- 渡したのは SKILL.md と保管庫のパス、写真は Read で見られること、C にだけ「PDF 化にはヘッドレス Chrome（html-to-pdf の手順）が使える」という環境の事実
- 頼んだ言葉（そのまま）：
  - A：「旅行記を書いて」
  - B：「旅行記を書いて。Canvas（一枚の地図）で」
  - C：「旅行記を書いて。印刷用（PDF）で」
  - B・C は最初の一言に「かたち」を一つ添えた（SKILL.md の 7 項「頼まれたら別ファイルで作る」を最初から頼んだ形）。追加の指示はこの一つだけ
